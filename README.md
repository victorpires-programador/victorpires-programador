## 🚀 Sobre Mim

Sou um entusiasta de tecnologia com formação técnica em Informática pela **ETERJ** e atualmente graduando em **Engenharia de Software** e **Segurança da Informação** pela **UNINTER**. 

Meu foco principal é a intersecção entre o desenvolvimento de sistemas robustos e a análise de vulnerabilidades. Tenho paixão por construir aplicações eficientes e explorar a superfície de ataque para implementar defesas mais sólidas (**Offensive Security**).

- 💼 **Experiência:** Desenvolvimento de sistemas utilizando o ecossistema .NET (C#, ASP.NET Core).
- 🎓 **Aprendizado:** Especializando-me em arquitetura de software e cibersegurança via UNINTER e Alura.
